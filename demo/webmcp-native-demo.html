WebMCP demo · native API shape

Mirrors the current WebMCP API rather than the earlier drafts: tools live on document.modelContext, getTools() returns RegisteredTool objects whose inputSchema is a JSON string, and executeTool() takes the tool object — passing its name throws The provided value is not of type 'RegisteredTool'.

Use it to check that the inspector shows title, description, triggerType and priority instead of "No input needed", and that the model sticks to the declared enums.
